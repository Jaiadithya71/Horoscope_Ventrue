# Public Balaji technique profile

[`balaji_public_technique.json`](balaji_public_technique.json) is an evidence-linked design input, not a claim to reproduce Balaji's private readings or a tested prediction model. The cited seven-video transcript analysis, timestamps and sourcing limits are in the [public-technique benchmark](../docs/balaji-haasan-public-technique-benchmark.md). The citations name source video plus second offset; use them to check each statement in the original-language recording. Automatic captions can mistranscribe Tamil astrological terms. Neither source speech nor paraphrase is authority for the model to make new unsupported claims.

The profile distinguishes **observed** operations, **mentioned but not derived** steps, the engine's actual implementation, and book alignment. In particular, Balaji mentions dasha/bhukti/antara, but the public footage does not show he uses the exact Phaladeepika XIX star-period algorithm. The engine's period arithmetic is a sourced candidate, not an attributed copy of his formula. Likewise, Leo's Saturn aspect-based work/family claim goes beyond the enabled book's simple eighth-house Saturn rule. Aquarius's child's marriage forecast goes beyond a generic children-related Jupiter-fifth rule. No one-person consultation is in this sample and no client outcome was scored.

Integration path: build a deterministic intermediate finding with `(input provenance, position, house/lord/aspect, source rule, audience qualifier, topic, interval, condition, uncertainty)`. Add calculated nakshatra/pada and timed ingresses before branching. Represent unsourced or conflicting factors as withheld findings, not fluent substitute prose. Only enable a book rule after the source PDF page is visually checked, and do not treat traditional astrology as scientifically validated guidance. Detailed source-versus-engine gaps remain visible in the machine-readable profile.
